# MatrixOne GoJieba 全文索引测试设计

> 基于 FullText 原始测试设计扩展；区分 GoJieba 特有契约、公共 FullText 回归和 ngram 对照

## 说明与覆盖

### 基本信息

- **MatrixOne 基线**：main（设计依据：feature #24271 / PR #24297）
- **功能入口**：CREATE FULLTEXT INDEX ... WITH PARSER gojieba
- **核心差异**：ngram 按连续 3 字符切片；gojieba 按静态中文词典分词
- **分词模式**：索引侧和查询侧均使用 HMM=false，保证 dictionary-only 结果一致
- **支持列类型**：CHAR、VARCHAR、TEXT、JSON、DATALINK；FullText 表必须有真实主键
- **评分算法**：TF-IDF、BM25
- **部署依赖**：五个 jieba 词典文件；支持 MO_JIEBA_DICT_DIR、二进制同级 dict 和 FHS 目录

## ngram 与 gojieba 对照基线

### 分词规则

- **ngram**：连续 3 个中文字符的重叠窗口
- **gojieba**：静态词典分词，HMM=false
- **验证方法**：对同一文本执行 fulltext_index_tokenize 并按 pos 排序
- **数据规模**：固定短文本
- **记录指标**：token、pos、DocLen
- **通过条件**：输出符合各自契约
- **备注**：必须保留结果证据

### 示例：我来到北京清华大学

- **ngram**：我来到、来到北、到北京、北京清、京清华、清华大、华大学
- **gojieba**：我、来到、北京、清华大学
- **验证方法**：分别建索引并读取隐藏索引词条
- **数据规模**：1 行
- **记录指标**：token 数和内容
- **通过条件**：与左侧预期一致
- **备注**：gojieba 不应产生 ngram 片段

### 索引构建

- **ngram**：先创建并完成查询后 DROP INDEX
- **gojieba**：在同一数据快照上重新创建
- **验证方法**：单机/TKE 分别运行
- **数据规模**：10 万/100 万/1000 万行
- **记录指标**：耗时、CPU、峰值内存
- **通过条件**：无失败；输出对照数据
- **备注**：不预设未经评审的性能门槛

### 索引规模

- **ngram**：统计隐藏表 token 行数和存储
- **gojieba**：统计隐藏表 token 行数和存储
- **验证方法**：相同数据、相同压缩和副本配置
- **数据规模**：同上
- **记录指标**：行数、对象大小、压缩后大小
- **通过条件**：结果可复现且无数据错误
- **备注**：记录 gojieba/ngram 比值

### 高频词 Top-K

- **ngram**：字符片段召回
- **gojieba**：词典词召回
- **验证方法**：命中率 1%/10%/50%，预热后各 10 轮
- **数据规模**：1000 万行
- **记录指标**：p50/p95、扫描量、RSS
- **通过条件**：各自语义结果正确；无 OOM/panic
- **备注**：保留 profile

### 词内子串

- **ngram**：短查询可能转前缀匹配
- **gojieba**：不保证匹配完整词内部子串
- **验证方法**：以清华大学/华大为对照
- **数据规模**：固定功能集
- **记录指标**：结果集合
- **通过条件**：差异与 parser 语义一致
- **备注**：不能将差异误判为 bug

### 未登录词

- **ngram**：不依赖词典
- **gojieba**：按 dictionary-only 实际切分
- **验证方法**：业务型号和专有名词集
- **数据规模**：1 万词
- **记录指标**：召回率、token 一致性
- **通过条件**：索引侧与查询侧无漂移
- **备注**：开发确认词典策略
